# BFSI Loan Portfolio & Credit Risk Analytics Dashboard
## Project Objective
The main objective of the project is to analyze the bank's loan portfolio, customer credit risk, defaults, NPA customers, loan types, branches, and DPD, so management can identify risky customers and branches and make better lending and collection decisions.

## Dataset used
- <a herf="https://github.com/skmobidul92/Data-Analyasis-BFSI-Dashboard/blob/main/BFSI_Credit_Risk_Clean.csv">Dataset</a>

## Business Question & KPIs
- How much total loan has been disbursed?
- Which branches have the highest loan exposure?
- How many customers have defaulted?
- How many customers are classified as NPA?
- Which loan types contribute the highest loan amount?
- Which branches have high-risk customers?
- What is the distribution of customers by credit score?
- Which customers have high DPD?
- Where should the bank focus its collection and risk-management efforts?

## Process
- Verify data for any missing values and sort out the same.
- Made sure data is consistant and clean with respect to data type, data formet and valuse used.
- Create KPI & Charts according to the question asked.
- Marge all charts in one Dashboard and apply slicer to make dynamic.

## Project Insight
- The bank has approximately ₹3 billion in total loan exposure, so effective credit-risk monitoring is important.
- 265 customers are classified as NPA, requiring focused recovery and risk-management activities.
- Bengaluru has the highest loan amount (~₹374M) and also the highest number of high-risk customers (5).
- There are 324 medium-risk customers. These customers should be monitored proactively to prevent migration into the high-risk category.
- Customers with lower credit scores can be subjected to stricter credit evaluation before additional lending.
- Loan-type analysis helps management understand which products are driving portfolio growth and where credit risk may be concentrated.

## Conclusion
“In conclusion, this project helped transform raw loan and customer data into meaningful business insights using Power BI. The dashboard provides a clear view of the bank’s loan portfolio, customer risk, defaults, NPA, DPD, credit scores, and branch performance.
The analysis helps management identify high-risk customers and branches, prioritize collection activities, monitor NPA and default trends, and make better credit and lending decisions. Overall, the dashboard supports data-driven risk management and improves visibility into the overall health of the loan portfolio.”
